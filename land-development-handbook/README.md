# 建築業土地開發全流程百科全書（互動網站版）

> 來源：飛書線上百科全書《建築業土地開發全流程百科全書》
> 位置：`D:\www\land-dev-encyclopedia\index.html`
> 版本：v1.0 ｜ 更新：2026-09-23

## 開啟方式
直接用瀏覽器打開 `index.html`（單檔自包含，不需伺服器、不需安裝任何依賴）。

## 功能
- **左側固定目錄**：10 篇 / 25 章完整章節導覽，目前章節高亮
- **首頁全書地圖**：十大模組卡片 + 全流程時間軸一頁速覽
- **全文即時搜尋**：頂欄輸入關鍵字（如「容積率」「建照」「水保」）即時跨章節檢索
- **日夜主題切換**：頂欄太陽/月亮切換，記住使用者選擇，初次造訪跟隨系統
- **麵包屑導覽 + 上/下一章**：知識庫式閱讀導航
- **Hash 路由**：`#/` 首頁、`#/part/p1` 篇首、`#/chap/c1` 章節、`#/search/關鍵字`，可直接分享連結
- **響應式**：桌面雙欄（目錄+內文），手機版側滑選單（漢堡鈕開關）

## 內容架構（10 篇 25 章）
1. 基礎總論：定義、分類、參與主體、法規體系
2. 前置作業：土地篩選、盡職調查(DD)、財務可行性
3. 土地取得與用地變更：五種取得模式、非都市土地變更流程
4. 規劃設計與建照：概念/細部設計、建照、雜照、開工備查
5. 工程施工：標準工序時間軸、階段勘驗、工地安全
6. 預售銷售：預售許可、價金信託、購屋貸款
7. 竣工使照：竣工查驗、使用執照
8. 產權登記交屋：第一次登記、分户移轉、法定保固
9. 成本稅務：成本結構占比、核心稅種
10. 風險與案例：風險矩陣、常見缺失、三大實務案例

## 技術
- 單一 HTML 檔，CSS/JS 全內聯，原生 JS（無框架、無建置工具）
- 字體：Noto Serif TC（標題）+ Noto Sans TC（內文），自托管字體鏡像
- 內容以 `const BOOK = {...}` 結構化資料驅動渲染，易於後續增修章節
- 配色：暖紙底 + 陶土橘強調色（亮/暗雙主題）

## 維護
- 新增章節：編輯 `<script>` 內 `BOOK.parts[].chapters[]`，新增一個 `{id,title,blocks:[...]}` 即可
- 區塊型別：`p`(段落)、`h3`(小標)、`ul/ol`(清單)、`quote`(重點引文)、`stats`(數字卡)、`cards`(說明卡)、`table`(表格)、`timeline`(時間軸)

## 備註
內容供專業學習與流程參考，實務作業請依各地方主管機關最新法規為準。

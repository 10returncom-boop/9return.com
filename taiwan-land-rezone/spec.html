3. 功能規格

3.1 頂欄 Header（<header class="top">）

  • 品牌列：Logo（「地」字 SVG 方塊）＋主標題「台灣22縣市重劃區 整合導覽」＋副標「全台總目錄 · 台中全目錄 · 24 篇買房白話攻略」。
  • 當前位置標記 <span class="loc" id="locChip">：由 renderLocChip() 依 CUR.slug 注入。
  • Sitemap 開關 #smToggle（按鈕＋標籤「網站地圖 Sitemap」＋▾）：initSmToggle() 切換 #mmWrap 開合。
  • MegaMenu #hdrMmInner：renderMegamenu() 注入全台 22 縣市「全展開網站地圖」，含 mm-count 統計與每縣市 accordion。

3.2 下拉選單（Dropdown）

  • 縣市下拉（county-dd）：renderNavDDs() 依 DATA 分區（六都／非六都）建置，initNavDDs() 處理開合與互斥。
  • 類型下拉（type-dd）：公辦市地重劃／自辦市地重劃／區段徵收／都市更新四類，點擊高亮對應 .mm-cat 群組（data-type-dd 事件）。

3.3 首頁主版區塊（Home）

  • 「全台 22 縣市 · 一縣市一目錄」：分「01 六都（6 縣市）／02 非六都（16 縣市）」兩群，每縣市為一張卡片，含縣市名連結（href="slug/index.html"）與行政代碼（A21001…A21022）。

3.4 Footer（<footer class="site-footer">）

  • 網站地圖 Sitemap（#footSitemap）：renderFootSitemap() 注入「全站導覽」＋各縣市連結＋類型細頁。
  • 資料聲明 .foot-note：資料來源、法源（市地重劃／土地徵收／都市更新條例）與免責聲明。
  • 本頁 小字連結 spec：指向 spec.html（本規格書）。

8.2 Excel → 網頁版 轉換流程

  1. Excel 整理：在 Final Excel 填妥/更新建案列（欄位如上）。
  2. 匯出 CSV：Excel「另存新檔 → CSV(UTF-8)」，欄位順序固定。
  3. 轉成 JSON：CSV 以工具轉為 JSON（對應 PROJECTS / 每重劃區 projects[]）。
  4. 寫入網站：以 JSON 替換網站 JS 內建案資料結構，前端自動渲染建案清單。

8.3 兩邊同步更新規則

  • 方向：以 Final Excel 為準 → 轉 JSON → 更新網站（單向匯出，避免兩邊互改衝突）。
  • 欄位對齊：Excel 欄位與網站 projects[] 鍵一一對應，缺欄留空不刪。
  • 版本化：每次轉檔前先備份舊 PROJECTS；網站與 Excel 同步標記版本（如 Final v1.2）。
  • 建議自動化：以排程（cron）定期將 Final Excel 轉出 CSV→JSON，並檢查欄位完整性後自動更新網站資料檔。

8.4 網頁版 Tab Pages（rezone-database.html）

  • 單檔自含：HTML+CSS+JS，重劃區資料內嵌、無外部框架；由 Final Excel 轉出之 JSON 產生。
  • 兩層 Tab：上層 22 縣市（六都／非六都分組），下層四大開發類型（公辦／自辦／區段徵收／都市更新）；下方卡片網格列出該縣市該類重劃區。
  • 建案下拉：每張重劃區卡片點擊展開建案（綁定 PROJECTS）；無建案時顯示 Final Excel 待補連結。
  • 入口：首頁 hub 第五張卡片「重劃區資料庫（網頁版）」與 footer「資料庫網頁版」連結。
